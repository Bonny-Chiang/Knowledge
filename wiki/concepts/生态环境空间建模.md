# 生态环境空间建模

## Definition

生态环境空间建模是把生态过程、环境变量和空间位置结合起来，解释或预测生态系统状态、功能和变化机制的方法体系。它关注的不只是“模型精度”，还包括空间尺度、环境协变量、扰动过程、机制解释和可复现数据流程。

## Common Objects

2026-07-28 组会资料显示，生态环境空间建模可以覆盖多个对象：

- 潮间带生态系统与生物多样性。
- 稻田土壤微生物群落、土壤碳库组分和生态系统多功能性。
- 红树林和滨海湿地 SOC 储量。
- 植物多样性对变暖的响应。
- 闪旱对城市核心区与郊区植被的影响。
- 极端降水后 GPP 响应和恢复期。
- AGB/SOC 关系与土壤碳空间预测。

## Modeling Logic

可复用的分析逻辑是：

```text
生态问题
  -> 空间对象和尺度
  -> 环境协变量
  -> 遥感/样点/栅格数据
  -> 空间建模
  -> 机制解释
  -> 不确定性和局限
```

## Method Families

- 遥感反演：用于获取植被、湿地、GPP、土地覆盖或生态系统状态。
- GIS 栅格分析：用于对齐分辨率、CRS、NoData、研究区边界和环境变量。
- 机器学习：用于非线性预测、变量重要性和空间制图。
- 结构方程模型：用于机制路径、直接效应、间接效应和变量关系解释。
- 层级分步抽样：用于在有限野外资源下安排样点优先级。

## Key Cautions

- 文件夹名、截图标题和正式论文标题可能不一致，引用前要回查原文。
- 相关性图、变量重要性和 SEM 路径不能自动等同于因果证明。
- 空间预测模型必须记录 CRS、分辨率、重采样方法、NoData、输入变量时间窗口和训练样本来源。
- 机制解释应回到生态过程，而不是停留在模型表现。
