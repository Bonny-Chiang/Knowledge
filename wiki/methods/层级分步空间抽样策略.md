# 层级分步空间抽样策略

## Purpose

层级分步空间抽样策略用于解决空间调查中“预算有限、不能一次性采集足够多样点”的问题。它把所有候选样点先整体设计出来，再按代表性等级分阶段采集。

## Core Idea

目标地理现象通常与环境协变量存在空间相关。通过对环境协变量进行多尺度聚类，可以近似目标现象从大尺度格局到局部格局的空间层级。

抽样时优先选择代表大尺度格局的样点，之后逐步加入代表局部格局的样点。

## Workflow

```text
目标地理现象
  -> 选择环境协变量
  -> 标准化和异常值处理
  -> 多轮 fuzzy c-means 聚类
  -> 隶属度阈值二值化
  -> 叠加得到 representative grade
  -> 识别 environmental cluster chain
  -> 按代表性等级、面积和隶属度排序
  -> 分阶段采样
```

## Priority Rules

样点选择按以下顺序排序：

- representative grade 越高，优先级越高。
- 同一 representative grade 下，representative area 越大，优先级越高。
- 同一 environmental cluster chain 下，representative level 越高，优先级越高。

## Why It Matters

传统随机、系统或分层抽样容易忽略空间变异层级。地统计抽样又常需要先验样本估计半变异函数。层级分步抽样的优势是能为“先采哪些、后采哪些”提供顺序，并让不同阶段的样点可以整合使用。

## Application Conditions

适合：

- 野外采样成本较高。
- 研究区较大或采样资源分阶段释放。
- 目标现象与环境协变量有较强空间关系。
- 需要数字土壤制图、生态环境制图、自然资源调查或低空遥感样点设计。

不适合：

- 环境协变量无法解释目标现象空间变化。
- 研究目标需要严格设计无偏估计的总体统计量。
- 聚类尺度和隶属度阈值缺少领域知识校正。

## Relation to Current Projects

该方法可为 [[生态环境空间建模]]、[[数字土壤制图]] 和未来低空遥感/自然资源巡查样点设计提供方法储备。对 [[低空政务巡查空间识别方法]] 也有启发：如果未来需要布设核验点或人工巡查样点，可以按空间代表性分阶段安排，而不是随机抽点。
