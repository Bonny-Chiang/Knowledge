# 空间环境建模汇报批注整理方法

## Purpose

本方法用于把组会截图、批注图片和汇报材料编译为可复用知识，而不是只保存图片或生成孤立摘要。

## Compilation Steps

1. 先保留原始截图目录，不修改图片。
2. 按文件夹名、截图标题、图表内容共同判断主题。
3. 记录文件夹名与截图内容不一致的情况。
4. 按“研究对象、数据来源、空间尺度、方法、核心机制、可复现风险”抽取知识。
5. 优先写入概念页和方法页。
6. 只有某一汇报本身需要长期引用时，才创建独立 source 页。
7. 若要正式引用结论，必须回查原论文或正式汇报文档。

## Extraction Template

```text
研究对象：
空间尺度：
数据来源：
主要变量：
方法：
核心发现：
批注意见：
可复现风险：
可沉淀知识：
后续需要回查：
```

## Quality Rules

- 不把截图中的红字批注直接当作论文结论。
- 不把模型图、相关性图或变量重要性图自动解释为因果关系。
- 对空间预测流程，必须记录 CRS、分辨率、重采样、NoData、变量时间窗口和样本来源。
- 对生态机制解释，必须区分统计关系、模型预测和过程机制。
